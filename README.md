This model was built using heart disease data from kaggle (data available on the github), it has 303 rows and 14 columns.
The data is free of any defect hence no need of any processing. So it was splitted into training and test data on the basis of 80 to 20 ratio.
After training the Logistic Regression model with training, the model was evaluated using classification report metrics and the result is has follow:
- Training and test data accuracy score is 0.83 and 0.90 respectively, showing that the model generalize well.
- The precision of training data on positive and negative status is 0.81 and 0.87, showing that the model rarely make false prediction
- Same thing goes to test data as well with 0.91 and 0.81 for positive and negative status respectively.
